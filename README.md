# w2a-site-problems

See a problem on the Word World Army website? Let us know!

## How to report something

1. Click **"Issues"** near the top of this page.
2. Click the green **"New issue"** button.
3. Pick **"Bug report"** — it'll give you a short form with a few questions to fill in.
4. Click **"Submit new issue"** when you're done.

You'll need a free GitHub account to do this. If you don't have one, it'll prompt you to sign up — that's the only extra step.

That's it — no need to know anything technical, just describe what you saw and where.
